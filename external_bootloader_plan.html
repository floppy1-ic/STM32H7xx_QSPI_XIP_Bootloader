Simple explanation

The bootloader lives in 128 KB internal flash at 0x08000000 and runs first after every reset.

The application is on external W25Q64: program at chip offset 0x00000000; execute at XIP 0x90000000 after memory-mapped mode.

The load request is a single word in Backup SRAM @ 0x38800000 (survives soft reset):

  • 1 — Run qspi_new_app_load() (program external flash; stub shows LCD then reset today).
  • 0 — LCD “Jump to app” → mmap → validate @ 0x90000000 → jump if valid; else bootloader poll (PE3 heartbeat).

In the idle loop, uart_recv_string() (Peripherals/UART1/uart_mcal) receives host text. If the string is SP, firmware calls app_load_enable() then qspi_new_app_load() → clear flag → soft reset (stub today).

Host tool: tools/saptashri_flash.py (see README). Full protocol: SP + 4-byte size, ACK 0x79, 256-byte chunks — planned inside qspi_new_app_load().

RegionAddressSizeRole

Six rules (boot plan)

  1. Bootloader @ 0x08000000 — Linker STM32H750VBTX_FLASH.ld, 128 KB.
  2. Check flag first — app_load_is_enabled() / app_load_is_disabled() on Backup SRAM @ 0x38800000.
  3. Flag = 1 — qspi_new_app_load(): today LCD stub 5 s → app_load_disable() → reset; later QSPI erase/write @ 0.
  4. Flag = 0 — LCD “Jump to app” → mmap + validate; if OK → qspi_app_jump_to_application(); if not → bootloader poll (PE3).
  5. While loop — PE3 heartbeat; uart_recv_string + strcmp(..., "SP") → app_load_enable() + qspi_new_app_load(); or if flag already 1, call load.
  6. After real program — Disable mmap → program → app_load_disable() → mmap on → soft reset; next boot flag 0 → jump.
Deferred: Internal flash sector 7 and external QSPI last-sector flags were removed — they conflicted with ST-LINK debug when tested from main every boot.

3 — App load session
Features/qspi_app_load/ — qspi_new_app_load() (stub: LCD 5 s, disable flag, reset). Planned: mmap off + erase/write.

Peripherals/QSPI_Flash/ — QSPI_Flash_DisableMemoryMappedMode, erase, write, mmap on.
5 — Jump when flag 0
Features/qspi_app_jump/ — qspi_app_is_valid, qspi_app_jump_to_application (not called from main.c yet).
6 — Soft reset
system_reset() in Core/Src/main.c; also NVIC_SystemReset() inside qspi_new_app_load().
7 — USART1 MCAL
Peripherals/UART1/ — uart_mcal: uart_send_*, uart_recv_*, uart_recv_string (returns byte count; main.c compares to "SP").
8 — Host flash tool
tools/saptashri_flash.py — SP + size + chunked program @ offset 0; documented in README.md.
9 — Idle UART in main
Core/Src/main.c — while(1): uart_recv_string then strcmp for SP → load path.
