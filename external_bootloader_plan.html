Simple explanation

The bootloader lives in 128 KB internal flash at 0x08000000 and runs first after every reset.

The application is on external W25Q64: program at chip offset 0x00000000; execute at XIP 0x90000000 after memory-mapped mode.

The load request is a single word in Backup SRAM @ 0x38800000 (survives soft reset):

  • 1 — qspi_new_app_load(): mmap off, erase full 8 MB (128×64 KB blocks), UART program @ offset 0. Success → flag 0 + reset; failure → flag 1 + mmap off + idle.
  • 0 — QSPI_Flash_Init → validate vectors (indirect 0x0B) → WeAct mmap → jump @ 0x90000000; else LCD status + idle (PE3 + UART SP).

On every boot: app_load_flag_sanitize() forces invalid BKPSRAM words to 0. QSPI_Flash_Init resets the chip, checks Winbond ID, and sets SR2.QE if needed.

Idle loop: uart_recv_string — if SP, app_load_enable() then qspi_new_app_load(). Host tool: tools/saptashri_flash.py (see README). Protocol: true/false, EC, WE, S+size → K/N, chunks → Y/N.

Bootloader verified: CmdRd and Mmap reads match (e.g. SP=24080000, PC=90000C5D). Old mmap settings (6 dummy cycles, alt 0x00) caused a byte slip at XIP; fixed per WeAct (alt 0xEF, 4 dummies). Application is a separate build — after jump, app must set VTOR, re-enable cache, and run SystemInit.

Six rules (boot plan)

  1. Bootloader @ 0x08000000 — Linker STM32H750VBTX_FLASH.ld, 128 KB.
  2. Sanitize flag — app_load_flag_sanitize() if word ∉ {0, 1}.
  3. QSPI init — QSPI_Flash_Init(): reset, ID, Quad Enable.
  4. Flag = 1 — Full UART program in qspi_new_app_load(); success resets with flag 0.
  5. Flag = 0 — qspi_app_is_valid_at_flash → mmap → qspi_app_jump_to_application or stay in BL.
  6. While loop — PE3 heartbeat; host SP → load (boot with flag 1 also enters load without SP).
Deferred: Internal flash sector 7 and external QSPI last-sector flags were removed — they conflicted with ST-LINK debug when tested from main every boot.

Repository mapping

1 — Bootloader @ 0x08000000
STM32H750VBTX_FLASH.ld: FLASH ORIGIN = 0x08000000, LENGTH = 128K
2 — Load flag (Backup SRAM)
Features/app_shared_ram/ — app_load_flag_sanitize, app_load_enable / disable, is_enabled / is_disabled @ 0x38800000.
3 — App load session
Features/qspi_app_load/ — qspi_new_app_load(): mmap off, erase 8 MB (64 KB blocks), UART RX, write; success → reset; fail → abort (flag 1, mmap off).
4 — QSPI driver
Peripherals/QSPI_Flash/ — QSPI_Flash_Init (reset, ID, QE), erase, write, mmap on/off.
5 — Jump when flag 0
Features/qspi_app_jump/ — qspi_app_is_valid_at_flash, qspi_app_jump_to_application (wired in main.c).
6 — Soft reset
system_reset() in Core/Src/main.c; also NVIC_SystemReset() inside qspi_new_app_load().
7 — USART1 MCAL
Peripherals/UART1/ — uart_mcal: uart_send_*, uart_recv_*, uart_recv_string (returns byte count; main.c compares to "SP").
8 — Host flash tool
tools/saptashri_flash.py — SP + size + chunked program @ offset 0; documented in README.md.
9 — Idle UART in main
Core/Src/main.c — while(1): uart_recv_string then strcmp for SP → load path.
